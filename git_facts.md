## Git Facts

by Ibuki Maeda

git is a kind of version control software, similar to the "track changes" feature of Microsoft Word or Google Documents.

git tracks changes to files in a special folder called a Repo, which is short for Repository.

git keeps a log of all the changes you have made to your files. Each change is called a Diff. You always provide a short comment describing what happened in the change.

git is really useful!
